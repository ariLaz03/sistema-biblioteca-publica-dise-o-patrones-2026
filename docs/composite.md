# Patrón Composite

## Descripción

El patrón Composite permite organizar objetos individuales y grupos de objetos mediante una estructura jerárquica de árbol.

## Aplicación en el proyecto

Se implementó para organizar las colecciones y subcolecciones de la biblioteca pública.

## Funcionalidades

- Crear colecciones.
- Crear subcolecciones.
- Organizar elementos jerárquicamente.
- Gestionar colecciones mediante una estructura común.
