# Pruebas unitarias

## Objetivo

Verificar el correcto funcionamiento de los patrones Composite y Decorator implementados en el proyecto.

## Archivos de prueba

- `tests/test_colecciones.py`
- `tests/test_decorator.py`

## Ejecución

Para ejecutar las pruebas, utilizar el siguiente comando desde la raíz del proyecto:

```bash
python -m pytest tests/ -v
```
