# Patrón Decorator

## Descripción

El patrón Decorator permite agregar funcionalidades adicionales a un objeto sin modificar directamente su estructura original.

## Aplicación en el proyecto

Se utilizó para incorporar servicios adicionales relacionados con los préstamos de libros.

## Funcionalidades

- Incorporación dinámica de servicios adicionales.
- Extensión de funcionalidades de los préstamos.
- Reutilización del comportamiento base.
